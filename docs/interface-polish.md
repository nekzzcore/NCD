# NCD: единая визуальная система

Изменения находятся в styles.css: обновлён основной контракт темы и добавлен общий завершающий слой компонентов. Тёмный фон #020617, поверхности #0f172a, границы #1e293b, основной акцент #4f46e5. Светлая тема сохраняется с тем же Indigo-акцентом. Экран входа использует те же поверхности и состояния.

Карточки используют радиус 12 px, внутренний отступ 20 px на десктопе и 16 px при ширине до 768 px. Таблицы и сетка календаря сохраняют компактные строки/ячейки, общий контейнер имеет те же границы и радиус. Заливка карточки ID стала плоской; декоративные тени и свечение не используются.

Hover-переходы кнопок, строк и карточек — 0,2 с ease. Страницы, табы и модальные окна открываются через короткий fade-in. Движение включается адресно, поскольку старые глобальные правила выключают анимации. При prefers-reduced-motion все новые переходы и анимации отключаются, включая модальные окна и onboarding. Ошибки полей остаются выделены контрастным цветом, focus-visible использует явный outline.

Проверки: CSS разобран css-tree без ошибок; контраст текста и кнопок в основной палитре выше 4,5:1. Пройдены существующие тесты тем, финансов, календаря, создания целей и навигации. Визуальная проверка скриншотами не выполнена: Chrome завершается с sandbox_host_linux shutdown: Operation not permitted в текущей среде. Геометрию на реальных устройствах следует проверить после установки/OTA.

Подготовка OTA: ./deploy-update.sh --prepare-only. Публикация явно подготовленной версии: ./deploy-update.sh VERSION "Единый интерфейс NCD". Подготовка не отправляет файлы в облако.
