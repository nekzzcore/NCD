# NCD: исправление мобильной PWA

## Архитектура и причина повторной загрузки старого UI

Корень приложения — #app в index.html, контроллер — GoalTracker в app.js,
навигация — switchView. React и Vite в проекте отсутствуют. Android Capacitor
берёт тот же www, который формируется из общих app.js/styles.css и модулей данных.
Отдельный упрощённый UI не создавался.

На рабочем столе обнаружена старая распакованная папка Desktop/NCD-PWA
с index.html от предыдущей сборки. Она не обновляется командами build:web.
Её повторная загрузка не публикует актуальные исправления.
Точный ответ CSS опубликованного сайта здесь не проверен; нельзя утверждать,
что ошибка загрузки стилей на удалённом сайте устранена до новой публикации.

## Что изменено

- index.html: три основные формы помещены в инертные template. Они не находятся
  в отображаемом DOM при закрытом окне, в том числе без CSS/JS.
- app.js: управление подключением/отключением форм, сохранение обработчиков
  после повторного открытия, защита от переключения формы во время сохранения.
  Регистрация service worker относительно document.baseURI для подпапок.
- index.html: проверка загрузки главного CSS; при сбое вместо голого приложения
  показывается сообщение с кнопкой обновления.
- styles.css: общая дизайн-система с тёмными карточками и фиолетовыми акцентами
  сохранена; мобильные формы открываются как bottom sheet, touch-кнопки >=44px,
  поля >=16px, высота учитывает VisualViewport и safe-area.
- bin/prepare-web.js: www и dist/web очищаются перед сборкой. CSS компилируется,
  имя его версии и кэш service worker зависят от содержимого сборки.
- sw.js: новая версия offline-кэша.
- bin/preview-web.cjs, package.json: npm run preview:web отдаёт именно готовую www
  без подмены скриптов или вставки dev-кода.
- Тесты: web-styles, modal-lifecycle; fixture goal-modal адаптирован к отключаемым формам.

Условное подключение реализовано средствами существующего JavaScript,
а не React. Попытка загрузить react/react-dom завершилась ENOTFOUND npm registry;
в локальном кэше пакетов нет. Требование именно React-рендеринга не выполнено.

## Сборка и папка публикации

```sh
cd /home/sayonara/goal-tracker
npm run build:web
npm run preview:web
```

Точная папка для Netlify: /home/sayonara/goal-tracker/www
Архив с index.html в корне: /home/sayonara/goal-tracker/dist/NCD-PWA.zip
Публикуйте всё содержимое www, не старую папку Desktop/NCD-PWA.
В www только одна HTML-страница — index.html; app.js и compiled styles.css на месте.

## Проверки

Прошли 10 целевых тестовых файлов: browser-storage, goal-storage, ios-layout,
modal-lifecycle, pwa, splash, subgoal-checklist, themes, web-build, web-styles.
Проверены создание/сохранение цели, достижения и заметки; закрытие и повторное
открытие форм; отсутствие двойных подписок; хранилище; ресурсы offline-кэша;
регистрация service worker в подпапке. В отдельном goal-modal — 16 из 17 тестов
проходят; сохраняется ранее выявленное расхождение приоритета новой подцели
(medium вместо ожидаемого high).

Реальный production-preview запущен, но сервер остановлен средой: listen EPERM.
Запуск Chrome также заблокирован запретом сокетов. Проверка DevTools 393×852,
отсутствия визуального overflow и полного визуального совпадения с APK не выполнена.
На компьютере без ограничений откройте http://127.0.0.1:8100 после preview:web;
DevTools → Toggle device toolbar → 393×852, DPR 3, touch. Проверьте обе темы,
вкладки, шторку деталей и три формы. Клавиатуру/safe-area дополнительно проверьте
на реальном iPhone в Safari и с домашнего экрана.

## Обновление и очистка кэша на iPhone

1. Сначала опубликуйте новую www на том же сайте Netlify.
2. Закройте NCD/PWA и вкладку Safari. Откройте постоянную HTTPS-ссылку онлайн,
   дождитесь загрузки, обновите страницу, затем закройте и откройте её ещё раз.
   Новый worker скачивает новую оболочку; локальный профиль при этом не удаляется.
3. Если сохранилась старая версия, сначала сделайте экспорт/синхронизацию данных.
   Очистка данных сайта может удалить localStorage, IndexedDB и локальную сессию.
4. Затем iPhone: Настройки → Приложения → Safari → Дополнительно → Данные сайтов
   (в старых iOS: Настройки → Safari). Найдите только домен своего Netlify-сайта
   и удалите его данные. При необходимости удалите прежнюю иконку NCD с домашнего
   экрана, откройте ссылку Safari заново и восстановите профиль из копии/синхронизации.
5. Safari → Поделиться → На экран «Домой» → Добавить.
