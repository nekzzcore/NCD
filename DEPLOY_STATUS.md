Альтернатива из корня проекта на компьютере с доступом в интернет:

```sh
npx netlify-cli login
npx netlify-cli deploy --dir=dist/web --no-build --prod
```

Инструкция для iPhone: открыть полученную HTTPS-ссылку в Safari →
Поделиться (квадрат со стрелкой вверх) → На экран «Домой» → Добавить.
Запустить NCD через новую иконку; первый раз дождаться загрузки онлайн.
